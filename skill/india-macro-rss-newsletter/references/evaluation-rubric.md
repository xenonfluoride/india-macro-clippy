# Newsletter evaluation rubric

Run the evaluator before delivery. It protects the requirements that matter most:

| Area | Pass condition |
| --- | --- |
| Provenance | The audit records RSS/Atom inputs, selections, and fetch failures. |
| Recency | Every selected item has a publication time within the configured window, normally 48 hours. |
| Selection | No routine auction, stock-tip, dividend, draft-IPO/listing, recycled growth-forecast, gadget-review, unrelated global-tech item, generic local-national, or state-politics-churn item reaches the page. Macro cards do not repeat a broad theme. |
| Analysis | Each card has a distinct two-sentence `Why it matters`: mechanism first, next signal or tradeoff second. |
| Structure | Market Tape and chart lead; Macro precedes National & Strategy, which precedes India Tech; the visible edition date is current; one catalyst module closes the issue. |
| Readability | The page has source links, responsive styling, focus styling, no duplicate stories, and no source-placeholder copy. |

Warnings call for a judgment check. Failures require a repair before delivery. If a feed is unavailable, record the failure in the audit and publish fewer stories instead of substituting web-search results.
